30-Day Attribution Rule

Visiting an ambassador's page (e.g. /ambassadors/bella/) or any link with ?ref=CODE stores that ambassador's code in the visitor's browser for 30 days. It survives navigation across the whole site and is only replaced if the visitor arrives through a different ambassador's link. Ticket/booking links always keep aff=CT184 — the ambassador code is never sent to ClubTickets, it's used only for our own internal attribution and commission reconciliation.
